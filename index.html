Overview

On many robot platforms, facial expressions are still manually authored as a small set of fixed presets: a designer hand-tunes parameters until the robot has one face per emotion. We replace this manual design process with automatic expression discovery. An RL agent explores a Furhat robot's facial action-unit controls directly, rendering each candidate configuration on the robot and scoring it with a facial expression recognizer trained on human faces. Over many trials, this feedback shapes the agent toward expressions that are more recognizable to humans — not toward a single preset, but toward a pool of diverse, valid candidate expressions per emotion. We evaluate the discovered expressions with a physical Furhat robot in an in-person user study, where participants judged them for recognizability, diversity, naturalness, and emotional intensity.

Code & Usage

This repository contains the full implementation: the REINFORCE/Actor-Critic trainer, the DAN-based facial expression classifier, and both baseline search methods, along with the Furhat-simulator setup needed to reproduce a run. 

# install dependencies
pip install -r requirements.txt

# RL policy gradient training (edit config.yaml first)
python policy_gradient_agent.py --config config.yaml

# Random search baseline (edit baselines/config_baseline.yaml first)
python baselines/run_baseline.py

# Bayesian Optimization baseline (edit baselines/config_bayesian.yaml first)
python baselines/run_bayesian.py

See the GitHub repository for the full setup guide, including the dual-monitor Furhat-simulator-plus-editor workflow the screen-capture classifier relies on.
